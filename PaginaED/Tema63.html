6.3 Búsqueda por funciones HASH

Un método que utiliza claves y funciones HASH para localizar información de manera eficiente.

¿Qué es la búsqueda por funciones HASH?

La búsqueda por funciones HASH es un método que permite localizar información mediante una clave. Para hacerlo, utiliza una función HASH que transforma esa clave en una posición dentro de una estructura llamada tabla HASH.

De esta manera, el programa puede acceder a la información sin tener que revisar todos los elementos uno por uno.

Características

  • Utiliza una función HASH para calcular posiciones.
  • Trabaja mediante claves que identifican los datos.
  • Permite realizar búsquedas rápidas.
  • Utiliza una estructura conocida como tabla HASH.
  • Puede presentar colisiones cuando dos claves generan la misma posición.

Funcionamiento

Primero se proporciona una clave para localizar un elemento. Después, la función HASH transforma esa clave en una posición dentro de la tabla. Finalmente, el programa utiliza esa posición para acceder a la información correspondiente.

Ejemplo:

Se utiliza la función: h(clave) = clave % 10

Clave Operación Posición
22 22 % 10 2
35 35 % 10 5
42 42 % 10 2
Las claves 22 y 42 generan la misma posición. A esta situación se le conoce como colisión.

Colisiones

Una colisión ocurre cuando dos o más claves producen la misma posición dentro de una tabla HASH. Para resolver este problema existen diferentes técnicas.

Encadenamiento

Consiste en almacenar varios elementos que comparten una posición dentro de una lista asociada a esa ubicación.

Direccionamiento abierto

Consiste en buscar otra posición disponible dentro de la tabla cuando ocurre una colisión.

Ejemplo de programación en C#

En C# se puede utilizar Dictionary para trabajar con una estructura que utiliza claves y valores. Esta colección utiliza mecanismos HASH internamente para localizar los elementos. 

using System;
using System.Collections.Generic;

class Program
{
    static void Main()
    {
        Dictionary<int, string> alumnos =
            new Dictionary<int, string>();

        alumnos.Add(101, "Daniela");
        alumnos.Add(102, "Carlos");
        alumnos.Add(103, "Maria");
        alumnos.Add(104, "Luis");

        int buscar = 103;

        if (alumnos.ContainsKey(buscar))
        {
            Console.WriteLine("Alumno encontrado: "
                + alumnos[buscar]);
        }
        else
        {
            Console.WriteLine("Alumno no encontrado");
        }
    }
}

Resultado esperado

Alumno encontrado: Maria

Ventajas

  • Permite realizar búsquedas rápidas.
  • Facilita el acceso a información mediante claves.
  • Es útil cuando se manejan grandes cantidades de datos.

Desventajas

  • Pueden ocurrir colisiones.
  • Necesita una función HASH adecuada.
  • El rendimiento puede disminuir si existen muchas colisiones.

Complejidad

Las tablas HASH pueden tener una complejidad promedio de O(1) para realizar búsquedas, siempre que la función distribuya adecuadamente las claves. En el peor caso, cuando existen muchas colisiones, la búsqueda puede llegar a O(n).

Conclusión

La búsqueda por funciones HASH permite localizar información de manera rápida utilizando claves. Es un método importante en programación porque facilita el acceso a los datos y se utiliza en diferentes estructuras y aplicaciones.
