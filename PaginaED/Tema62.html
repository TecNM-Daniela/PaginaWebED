6.2 Búsqueda binaria

Un algoritmo que reduce el espacio de búsqueda dividiendo los datos ordenados a la mitad.

¿Qué es la búsqueda binaria?

La búsqueda binaria es un método que permite localizar un elemento dentro de un conjunto de datos ordenados. Su funcionamiento consiste en dividir repetidamente el espacio de búsqueda en dos partes hasta encontrar el elemento deseado.

En cada paso se compara el valor buscado con el elemento que se encuentra en la posición central. Dependiendo del resultado, se continúa buscando en la mitad izquierda o derecha.

Características

  • Necesita que los datos estén ordenados.
  • Divide el espacio de búsqueda en dos partes.
  • Reduce la cantidad de comparaciones necesarias.
  • Es eficiente para conjuntos de datos grandes.
  • Utiliza posiciones iniciales, finales y centrales.

Funcionamiento

Primero se identifica el elemento central del arreglo. Después se compara con el valor buscado. Si el valor es menor, se continúa en la mitad izquierda; si es mayor, se busca en la mitad derecha. El procedimiento se repite hasta encontrar el dato o determinar que no se encuentra.

Ejemplo:

Arreglo ordenado: 3, 7, 12, 18, 24, 31, 45

Dato buscado: 24

1. Se compara con el número central: 18.
2. Como 24 es mayor, se busca en la mitad derecha.
3. Se compara con 31 y después con 24.
4. El elemento se encuentra en la posición 4.

Ejemplo de programación en C#

En este ejemplo se utiliza un arreglo ordenado y las variables inicio, fin y medio para realizar la búsqueda. 

using System;

class Program
{
    static void Main()
    {
        int[] numeros = { 3, 7, 12, 18, 24, 31, 45 };
        int buscar = 24;

        int inicio = 0;
        int fin = numeros.Length - 1;
        int posicion = -1;

        while (inicio <= fin)
        {
            int medio = (inicio + fin) / 2;

            if (numeros[medio] == buscar)
            {
                posicion = medio;
                break;
            }
            else if (numeros[medio] < buscar)
            {
                inicio = medio + 1;
            }
            else
            {
                fin = medio - 1;
            }
        }

        if (posicion != -1)
        {
            Console.WriteLine("Elemento encontrado");
            Console.WriteLine("Posicion: " + posicion);
        }
        else
        {
            Console.WriteLine("Elemento no encontrado");
        }
    }
}

Resultado esperado

Elemento encontrado
Posicion: 4

Ventajas

  • Es más rápida que la búsqueda secuencial en conjuntos grandes.
  • Reduce el espacio de búsqueda en cada paso.
  • Realiza menos comparaciones cuando los datos están ordenados.

Desventajas

  • Necesita que los datos estén ordenados.
  • Puede requerir un proceso previo de ordenamiento.
  • Su implementación puede ser más complicada que la secuencial.

Complejidad

La búsqueda binaria tiene una complejidad temporal promedio y en el peor caso de O(log n), debido a que reduce a la mitad el espacio de búsqueda en cada paso. En el mejor caso es O(1), cuando el elemento está justo en la posición central.

Conclusión

La búsqueda binaria es un método eficiente para encontrar información cuando los datos están ordenados. Su principal ventaja es que reduce rápidamente la cantidad de elementos que necesita revisar, por lo que resulta útil cuando se trabaja con conjuntos de información grandes.
