6.1 Búsqueda secuencial

Un método sencillo que permite encontrar información revisando los elementos uno por uno.

¿Qué es la búsqueda secuencial?

La búsqueda secuencial, también conocida como búsqueda lineal, es un método que consiste en recorrer los elementos de una lista o arreglo desde el principio hasta encontrar el dato que se está buscando.

El algoritmo compara cada elemento con el valor solicitado. Si encuentra una coincidencia, devuelve su posición. Si termina de revisar todos los elementos y no encuentra el dato, indica que no existe.

Características

  • Revisa los elementos uno por uno.
  • No necesita que los datos estén ordenados.
  • Es fácil de implementar y comprender.
  • Puede utilizarse en arreglos y listas.
  • Su rendimiento depende de la cantidad de elementos.

Funcionamiento

Para realizar una búsqueda secuencial, se comienza desde el primer elemento del arreglo y se compara con el valor que se desea encontrar. Si no coincide, se continúa con el siguiente elemento hasta localizarlo o llegar al final.

Ejemplo:

Arreglo: 14, 8, 25, 11, 30

Dato buscado: 11

El algoritmo revisa 14, después 8, luego 25 y finalmente encuentra el número 11 en la posición 3. Las posiciones comienzan desde 0.

Ejemplo de programación en C#

El siguiente programa utiliza un arreglo y un ciclo para comparar cada número hasta encontrar el valor solicitado. 

using System;

class Program
{
    static void Main()
    {
        int[] numeros = { 14, 8, 25, 11, 30 };
        int buscar = 11;
        int posicion = -1;

        for (int i = 0; i < numeros.Length; i++)
        {
            if (numeros[i] == buscar)
            {
                posicion = i;
                break;
            }
        }

        if (posicion != -1)
        {
            Console.WriteLine("Elemento encontrado");
            Console.WriteLine("Posicion: " + posicion);
        }
        else
        {
            Console.WriteLine("Elemento no encontrado");
        }
    }
}

Resultado esperado

Elemento encontrado
Posicion: 3

Ventajas

  • Es sencilla de programar.
  • No requiere ordenar previamente los datos.
  • Funciona con diferentes cantidades de elementos.

Desventajas

  • Puede revisar muchos elementos antes de encontrar el dato.
  • Su rendimiento disminuye cuando aumenta la cantidad de información.
  • No es la opción más eficiente para conjuntos de datos grandes.

Complejidad

La complejidad temporal promedio y en el peor caso es O(n), porque puede ser necesario revisar todos los elementos del arreglo. En el mejor caso es O(1), cuando el elemento se encuentra al inicio.

Conclusión

La búsqueda secuencial es un método práctico y fácil de utilizar cuando se trabaja con conjuntos de datos pequeños o cuando la información no está ordenada. Aunque puede ser menos eficiente con grandes cantidades de datos, es una buena opción para comprender el funcionamiento de los algoritmos de búsqueda.
